복잡했던 보험 설계 프로세스,
MeAI 가입설계 도우미로 간단하게

모바일에서도 간단한 질의만으로 가계약 생성이 자동 연동됩니다.

진행 방법 보장분석 MeAI ➡ 맞춤대화 ➡ 가계약 생성 연동

이제 모바일에서도 고객 맞춤형 [보장분석]부터 [가계약 생성]까지 프로세스의 단절 없이 원스톱(One-Stop)으로 매끄럽게 연결되어 영업 효율을 극대화합니다.

업그레이드된 '모바일 MeAI'를 통해 더 빠르고 정확한 설계를 직접 경험해 보시기 바랍니다.

※ 아래 첨부된 화면 이미지를 참고하시기 바랍니다.
PART 1

가계약 생성하기

STEP 1

가계약 생성 의도 요청

MeAI 대화창에 "가계약 해줘"라고 입력하면 가계약 생성 의도를 인식하고 프로세스를 시작합니다.

STEP 2

가계약 생성 클릭

보험료 정보를 확인 후 "생성하기" 버튼을 눌러 가계약 생성을 요청합니다. 요청 즉시 생성이 시작됩니다.

STEP 3

가계약 생성 요청 및 대기

결과 도착까지 최대 5분이 소요됩니다. 고객 니즈와 제안 담보를 기준으로 가장 유사한 가계약을 설계합니다.

⚠️

가계약 생성 시까지 최대 5분 정도의 시간이 소요되며, 해당 시간 동안 MeAI 사용이 불가합니다. 처리 중에는 앱을 종료하거나 새로고침하지 마세요. 작업이 중단되면 처음부터 다시 요청해야 할 수 있습니다.

PART 2

가계약 생성 후 이동하기

STEP 4 · 7 · 8

장기보험 가입설계 화면으로 이동 및 가계약 조회

생성 완료 후 "장기보험 가입설계화면 이동" 버튼을 누르면 이동 확인 팝업이 표시됩니다.

"이동" 클릭 시 MeAI 화면이 닫히고 장기보험 가입설계 화면으로 이동합니다.
가계약조회(수정/메시지/서류발송처기)를 클릭하면 MeAI에서 생성한 가계약 번호를 확인할 수 있습니다.
